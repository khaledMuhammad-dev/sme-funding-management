Every hue ships as a pair — fill and ink. The terracotta from the reference (#e4774a) is beautiful but only reaches 2.4:1 against parchment, so it can never carry text. --terracotta is therefore fill-only and always pairs with a navy label; --terracotta-ink (#b14019) is the darkened version used whenever the colour has to be a word or an icon. Same rule for brass. This is the single most important convention here — reach for -ink the moment the colour becomes type.

Colour is never the only signal. Each badge carries a text label, and the row rail repeats the state as position. For deuteranopia the risky pair is approved green vs incomplete brass — they sit 86° apart in hue and 0.02 apart in lightness, so the label does the work. Never render a status as a bare dot without its label.

06 · Chart palette

Five series, hue-separated, legible on both grounds

Submitted Screened Interviewed Approved Disbursed
Series run navy → terracotta → brass → teal → violet: a lightness ramp as well as a hue ramp, so the set survives greyscale printing and the common colour-vision deficiencies. Legends always carry text — never rely on the swatch alone.

07 · Accessibility audit

Computed live from the tokens — flip the theme and watch it re-run

…Running…
PairSampleRatioNeedsResult
Thresholds: 4.5:1 for body text (WCAG 2.2 AA 1.4.3), 3:1 for large text ≥24 px and for UI component boundaries and focus indicators (1.4.11). Beyond contrast, the rules baked into the components above: focus is a 2 px --ring outline with 2 px offset on every interactive element; error state is border + icon + text, never colour alone; minimum touch target 44 px; prefers-reduced-motion disables all transitions; and every status badge names its state in words.
